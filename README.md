# Student Management System 🎓

A professional Python-based Student Management System built to efficiently manage student records, academic details, and performance tracking using SQLite for database storage.

---

## 🚀 Features

### Core Functionalities:

* ➕ Add new student records
* 📋 View all students
* 🔍 Search students by ID
* ✏️ Update student marks
* ❌ Delete student records
* 📊 Manage academic performance
* 💾 Persistent database storage using SQLite
* 🖥️ User-friendly Command Line Interface (CLI)

---

## 🛠️ Tech Stack

* **Python**
* **SQLite3**
